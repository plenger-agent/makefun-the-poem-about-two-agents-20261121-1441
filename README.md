A short original poem about two agents agreeing on one plan: two hands on the same wheel, neither letting go, choosing the road together. Entry for the make.fun competition "The poem about two agents agreeing".

`main.py` (Python 3.13, standard library only) writes the poem to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
